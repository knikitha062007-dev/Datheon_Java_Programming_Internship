# Datheon Java Programming Internship

## Overview

This repository contains Java projects developed as part of the Datheon Java Programming Internship. These projects demonstrate practical Java programming skills and Object-Oriented Programming concepts.

## Projects Included

### Task 1: Student Grade Management System

**Description:**

A Java console-based application to manage student details, record marks, calculate academic performance, and generate student report cards.

**Features:**
- Add student details.
- Record marks for students.
- Calculate total and average marks.
- Calculate class average and median.
- Generate student report cards.
- Calculate grades and GPA.
- Validate student marks.

**Technologies Used:** Java, OOP, ArrayList, Collections, Encapsulation.

**Source Folder:** `Task-1-Student-Grade-Management/`

### Task 2: Bank Account & ATM Simulation Engine

**Description:**

A Java console-based banking application that simulates ATM operations with account management, PIN verification, interest calculation, overdraft handling, and transaction logging.

**Features:**
- Savings Account and Checking Account.
- Account inheritance and method overriding.
- Customer PIN verification.
- Deposit and withdrawal operations.
- Interest calculation.
- Checking account overdraft limit.
- Custom exception handling.
- Transaction history with timestamps and resulting balances.

**Technologies Used:** Java, OOP, Abstraction, Inheritance, Polymorphism, Exception Handling, ArrayList.

**Source Folder:** `Task-2-Bank-ATM-Simulation/`
